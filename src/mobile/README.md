# lingoRoad mobile

Ứng dụng Flutter dành cho người học của lingoRoad.

## Yêu cầu

- Flutter SDK tương thích Dart `>=3.6.0 <4.0.0`.

## Cài đặt và kiểm tra

```powershell
cd src/mobile
flutter pub get
flutter analyze
flutter test
```

## Chạy ứng dụng

```powershell
flutter run
```

Web hoặc Windows:

```powershell
flutter run -d chrome
flutter run -d windows
```

Phần cấu hình API và xác thực được bổ sung trong các task FE-02 và FE-03.
